# Política de Privacidade — Daudas Xianyu Helper

Esta extensão **NÃO** coleta, armazena, vende ou transmite dados pessoais.

## Dados lidos
Texto visível das páginas do Goofish e CSSBuy, processado **localmente** no navegador.

## Requisição externa
Apenas à API pública [AwesomeAPI](https://economia.awesomeapi.com.br) para cotação CNY→BRL.
Nenhum dado do usuário é enviado nessa requisição.

## Armazenamento local
Taxa de câmbio e preferências salvas no `localStorage` do navegador. Nunca em servidores externos.
